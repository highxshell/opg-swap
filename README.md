# OPG-SWAP

One-page site for OPG-SWAP, an engine swap and car repair shop in Astana.
Everything lives in `index.html` (plus `favicon.svg`); there is no build step.

The site is served by GitHub Pages from the `main` branch at https://astanaswap.kz (the domain is set in `CNAME`). To update it, edit `index.html`, commit and push; the live site refreshes within a minute or two.
